🧪 Testes Manuais Recomendados

Teste 1: Corte Básico

  1. Acesse: http://localhost:8081
  2. Vá para "Painel Criativo"
  3. Clique em "Editor de Imagens" (ícone Sliders)
  4. Cole a URL:
https://picsum.photos/800/600
  1. Clique em "EXECUTAR AGORA"
  2. Selecione proporção "1:1 (Quadrado)"
  3. Arraste para posicionar o corte
  4. Clique em "Salvar Imagem"
  5. ✓ Imagem deve ser baixada como PNG

Teste 2: Filtros

  1. Carregue uma imagem
  2. Vá para aba "Filtros"
  3. Ajuste brilho para 150%
  4. Ajuste contraste para 120%
  5. Ajuste saturação para 80%
  6. ✓ Pré-visualização deve atualizar em tempo real
  7. Clique "Girar 90°" várias vezes
  8. ✓ Rotação deve funcionar perfeitamente

Teste 3: Redimensionamento

  1. Carregue uma imagem
  2. Vá para aba "Tamanho"
  3. Clique em "512x512 (Avatar)"
  4. ✓ Proporção deve mudar para 1:1
  5. Clique em "1920x1080"
  6. ✓ Proporção deve mudar para 16:9
  7. Ajuste qualidade a 70%
  8. Salve e compare tamanho dos arquivos
